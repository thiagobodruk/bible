# Takedown and copyright policy

This project distributes Bible texts collected from third-party sources. The
[MIT License](LICENSE) covers only the structure of the files, the scripts and
the formatting work. It does **not** grant any rights over the Bible texts, which
belong to their authors, publishers or rights holders.

If you are a rights holder and believe a version in this repository is
distributed without your permission, we want to hear from you and will act
quickly.

## How to send a request

**Option 1 — GitHub issue (recommended).** Open a
[takedown request](https://github.com/thiagobodruk/bible/issues/new?template=takedown-request.yml).
Issues are public, so do not include private personal data.

**Option 2 — GitHub's DMCA process.** You can send a notice directly to GitHub
following [GitHub's DMCA takedown policy](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy).
GitHub will notify the maintainer.

## What to include

- The file(s) affected (for example `json/xx_abc.json` and `xml/xx_abc.xml`) or the version name.
- Who you are and how you hold the rights (owner, publisher, authorized agent).
- What you want: removal, or a different credit or license notice.

## What happens next

- We will acknowledge the request and, where it looks valid, remove the affected
  version from the `master` branch as soon as possible (target: within 7 days),
  and update the README, `json/index.json` and the wiki.
- Removing a file from `master` does not erase it from older commits, tags,
  releases, forks or clones. If you need the history cleaned too, say so in the
  request and we will evaluate it.
- Requests can also be about crediting: if a version is correctly distributed but
  needs a different attribution or license notice, we will update it.

## For users of the data

The repository is provided "as is", without warranty of any kind, and the
maintainer is not responsible for how third parties use the data. You are
solely responsible for checking the license of each Bible version you use and
for complying with it. Versions may be removed at any time following a request
described above.
